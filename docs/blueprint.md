# **App Name**: ChemCalc Pro

## Core Features:

- Formula Calculators: Provide a set of specialized scientific calculators based on user-provided formulas, including Acid Value, Hydroxyl Value, Saponification Value, Iodine Value, Anionic Content Adjustment, Standard Dilution, Percentage Calculator, Caustic Trial, Batch Caustic Add, and Short Batch Adjustment.
- Real-time Calculation: Automatic calculation updates upon input changes to allow for the live update of outputs based on edits.
- Save Frequent Batches: User can save and retrieve frequently used batch configurations or component sets to local storage for easy recall.
- Export Calculation Results: Export results of calculations for documentation purposes and store calculation configuration data.
- Guidance Tooltips: Clear and concise tooltips guide users in data input, with friendly labels mirroring spreadsheet terminology to create a straightforward user experience.
- Optional Light/Dark Mode: Offer an optional light/dark mode switch to accommodate various lab conditions and user preferences to enable an adaptive user experience.
- Display Calculation Formula: Each calculator page displays the actual calculation formula in small text underneath the result for enhanced transparency and understanding.

## Style Guidelines:

- Primary color: Strong sky blue (#74C0FC) to highlight interactivity in a way remniscent of laboratory notebook styling, creating a professional and trustworthy atmosphere.
- Background color: Light blue-gray (#E5E7EB), subtly desaturated for comfortable contrast.
- Accent color: A vibrant purple-blue (#8596ff), drawing from laboratory dyeing practices, emphasizing critical buttons and key actions to guide user interaction.
- Font: 'Inter', a grotesque-style sans-serif to promote a modern, machined, objective, and neutral design, making it ideal for headlines or body text.
- Icons should be simple and geometric to quickly communicate functionality.
- Maintain a clean, structured layout with clear visual hierarchy to facilitate quick and accurate data entry.
- Incorporate subtle animations during transitions and calculations to provide feedback without being distracting.
